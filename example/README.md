# Example

Discord Presence is a Lumide plugin, not a library: install it and it
works.

1. In Lumide, open **Plugins**, search for **Discord Presence** and
   install it.
2. Keep the Discord desktop app open.

Your Discord status then shows what you're working on:

```
Playing Lumide
Editing main.dart
In my_app
🕒 01:23:45 elapsed
```

To keep a project's names off Discord, open it and pick
**Hide "my_app"** from the Discord icon in the status bar. Discord then
shows:

```
Playing Lumide
Editing a Dart file
🕒 01:23:45 elapsed
```

Everything else, such as privacy mode, buttons and idle, is in the
[README](../README.md).
